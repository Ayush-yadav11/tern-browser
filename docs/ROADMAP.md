# Tern roadmap

Features seen in open source browsers that suit Tern, in rough order. Ideas only: Tern doesn't
reuse their code, names or artwork. Tern stays light, and has no AI features.

## Done

- Ad and tracker blocking, Tor tabs, proxy, side tabs, bookmarks, history, downloads, PDF viewer

## In order

1. [x] Command palette: search tabs, bookmarks, history and actions (Zen, Vivaldi)
2. [x] HTTPS-only mode (LibreWolf, Tor Browser)
3. [x] Remove tracking parameters from links, and send Global Privacy Control (Brave, LibreWolf)
4. [x] Search shortcuts such as `!w` and `!yt` in the address bar (Helium, DuckDuckGo)
5. [ ] Remember zoom per site, and per-site settings in one place (most browsers)
6. [ ] Reader view (Min, Firefox)
7. [ ] Bookmark folders, and import from other browsers (most browsers)
8. [ ] Tab groups or workspaces (Min's tasks, Zen)
9. [ ] Split view: two pages side by side (Zen, Vivaldi)
10. [ ] Full-text search of pages you've visited, stored only on this PC (Min)
11. [ ] Set Tern as the default browser (most browsers)
12. [ ] Multiple windows (most browsers)
13. [ ] User scripts and user styles per site (Min, Floorp)
14. [ ] Spell check, if it can work without contacting Google (most browsers)
15. [ ] Password manager, or integration with one (Min)

## UI polish, between features

- Tab open and close animation, with reduced motion respected
- Tab hover previews
- New tab page: most visited, optional wallpaper
- First-run setup: theme, layout and search engine
- More themes, including following the Windows light or dark setting
- Clearer loading indicator in the address bar

## Won't do

- Disguising Tern to get past Google's sign-in check or any other site's security check
- AI features of any kind
- Anything that lets Tor tabs or the proxy connect without them
